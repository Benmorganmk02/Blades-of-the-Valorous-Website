This file is a template and is NOT shown on the site (files starting with _ are skipped).
Copy it, give the copy a new name like `the-sunken-crown.md`, and fill it in.

- `world`: the world's folder name, e.g. `aetherastra` or `malconia`. Leave it out for a module that fits any world.
- `subsection`: where in that world it's set. Use a time period's folder name without the number
  (`the-age-of-sovereignty`), a section inside one (`the-age-of-myth/the-creation`), or a general
  chapter (`peoples`). Leave it out if the module covers the whole world.
- `level`, `players`, `length`: optional. Delete any line you don't need.

Everything below the header is the module itself: hooks, scenes, encounters, maps, rewards.
