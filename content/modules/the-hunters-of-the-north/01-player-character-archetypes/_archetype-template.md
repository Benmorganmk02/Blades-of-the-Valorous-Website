This file is a template and is NOT shown on the site (files starting with _ are skipped).
To add an archetype, create a new file in this folder named like `07-the-warden.md`,
copy this header into it, and fill it in:

- `title`: the archetype's name.
- `order`: where it sits in the list (1 comes first).
- `tags`: optional short labels shown as small pills, separated by commas. Delete the line if not needed.
- `summary`: the short text shown on the archetype's card.
- `races`: which races can take this archetype, e.g. `races: Aeltheran, Dúrhennar`. `all` means every race.

Anything written below the header becomes the archetype's own page (background, suggested attributes and skills,
starting gear, play tips…). An archetype with only a header still appears in the list, just without a page to open.
